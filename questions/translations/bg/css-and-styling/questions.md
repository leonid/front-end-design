### 1. Как подхождате към стилизирането в React? Сравнете CSS-in-JS, Styled Components, Sass и TailwindCSS.

Избирам инструменти за стилизиране според сложността на проекта, предпочитанията на екипа, мащабируемостта и изискванията за производителност.

| Техника | Предимства | Недостатъци |
| ----------------------------------------------- | --------------------------------------------------------- | ---------------------------------------------------------------- |
| **CSS-in-JS**(напр. Emotion, styled-components) | Ограничени стилове, динамични теми, стилове редом с компонентите | Натоварване по време на изпълнение, по-трудно извличане на критичния CSS |
| **Styled Components** | Подход, ориентиран към компонентите, поддръжка на теми, автоматично ограничаване на обхвата | Размер на bundle, парсване по време на изпълнение, сложност на инструменталната верига |
| **Sass (SCSS)** | Влагане, променливи, миксини, зряла инструментална поддръжка | Глобален обхват по подразбиране, необходимо е ръчно използване на BEM или конвенции |
| **TailwindCSS** | Първо помощни класове, бързо прототипиране, адаптивност по подразбиране | Многословни имена на класове, крива на обучение, слабо разделяне на отговорностите |

**Изборът ми по подразбиране**: Tailwind за екипи с бързо темпо или системи за дизайн; Styled Components за библиотеки от компоненти с поддръжка на теми.

### 2. Какви стратегии използвате, за да осигурите адаптивност на приложение на React към различни устройства?

- **Дизайн с приоритет на мобилните устройства** чрез адаптивни единици (`rem`, `%`, `vh/vw`) и медийни заявки.
- **CSS Grid / Flexbox** за адаптивност на оформлението.
- **TailwindCSS** или помощни класове (`sm:`, `md:`) за стилизиране според точките на прекъсване.
- Когато е необходимо, използвайте хука `useWindowSize` или библиотеки като `react-responsive` за поведение, а не само за стил.

### 3. Как бихте реализирали превключвател за тъмен режим в приложение на React?

Използвайте състояние `theme` (или контекст), превключвайте `class` върху `body` или `html` и задавайте стиловете условно.

**Пример с CSS-in-JS**: използвайте `ThemeProvider` със светла и тъмна тема.

### 4. Проектирайте многократно използваем бутонен компонент в React със Styled Components, който поддържа няколко варианта (напр. primary, secondary).

```jsx
import styled from 'styled-components';

const Button = styled.button`
  padding: 0.5rem 1rem;
  border-radius: 4px;
  font-weight: bold;
  background: ${({ variant }) =>
    variant === 'primary' ? '#007bff' : '#6c757d'};
  color: white;
  border: none;
  cursor: pointer;

  &:hover {
    opacity: 0.9;
  }
`;

// Използване:
<Button variant="primary">Save</Button>
<Button variant="secondary">Cancel</Button>

```

### 5. Какви са предимствата и недостатъците на TailwindCSS в голям проект на React с няколко разработчици?

**Предимства:**

- Последователност чрез помощни класове.
- Отличен избор за **системи за дизайн** и **адаптивни оформления**.
- Намалява превключването на контекста между CSS и маркировката.
- Осигурява висока **скорост на разработка**.

**Недостатъци:**

- Многословните имена на класове могат да навредят на четимостта.
- За потребителски компоненти може да е необходима работа по плъгини или допълнително абстрахиране (напр. `clsx`, `cva`).
- Логиката за стилизиране е вградена в JSX — повторното ѝ използване е по-трудно, ако не е абстрахирана правилно.

  **Намаляване на недостатъците**: използвайте помощни инструменти (`clsx`, `tailwind-variants`) и дизайн токени, за да намалите дублирането.

### 6. Как управлявате конфликтите на специфичност в CSS в приложение на React, което използва както глобални, така и ограничени до компоненти стилове?

- **Предпочитайте стилове, ограничени до компоненти** (напр. CSS Modules, styled-components).
- Използвайте префикси в глобалните стилове (`body.my-app`) и избягвайте общи селектори.
- Използвайте **BEM** или конвенции, когато са необходими глобални стилове.
- Избягвайте `!important`, освен ако не е абсолютно необходимо.
- Проверявайте стиловете чрез DevTools → проследяване на специфичността.

### 7. Как реализирате CSS анимация в React, която се задейства при промяна на състоянието?

```jsx
import "./Fade.css"; // .fade { opacity: 0; transition: opacity 0.3s } .fade.show { opacity: 1; }

const FadeComponent = ({ visible }) => (
  <div className={`fade ${visible ? "show" : ""}`}>Hello</div>
);
```
